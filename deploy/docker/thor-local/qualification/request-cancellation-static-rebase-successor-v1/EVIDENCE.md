## What this proves

- The exact frozen bytes of eight production files and five tests are present.
- Eight stale-current predecessor package trees remain byte-identifiable through independent raw, canonical, and tree identities.
- Refreshed expected contracts contain 13 LVS MCP tools, 18 LVS routes, and 28 RT-VLM Thor-local routes.
- The current API inventory retains 330 declared and 329 normalized REST operations.
- The RT-VLM 28th route is explicitly a Thor-local exact request-id cancellation extension over the documented denominator of 27.
- The contract permits two exact, local, source-locked pytest invocations (isolated RT-VLM and normal LVS) and otherwise prohibits subprocesses, networking, Docker, and service lifecycle.

## What this does not prove

`static-receipt.json` contains `runtime_evidence: []` and records zero promotions. Static unit tests do not prove deployed HTTP/MCP disconnect handling, GPU or queue quiescence, CA-RAG/Elasticsearch cleanup, or end-to-end behavior on Thor. Those remain explicit deployed-runtime blockers and require separately authorized runtime receipts.

The exact allowed invocations passed locally: the isolated RT-VLM lane reported 18 tests passed, and the LVS lane reported 97 tests plus 82 subtests passed. These are deterministic static/unit-test observations, not deployed runtime evidence.

Admission, executable, authorization, and `passed_current` states are unchanged. Historical predecessor receipts remain historical; this successor does not reinterpret them as current runtime evidence.

Warehouse sample data is excluded. This package neither qualifies nor requires the Warehouse sample bundle.
