# LVS MCP current-runtime qualification

This package proves the complete NVIDIA VSS 3.2.1 13-tool LVS MCP catalog over
the deployed loopback-only SSE transport. It invokes five read-only
non-inference tools and a disposable `add_file` / `list_files` /
`get_file_info` / confirmed `delete_file` lifecycle through a real MCP client.
Traversal and mismatched-confirmation negatives must fail with sanitized tool
errors.

The executor generates one tiny H.264 MP4 under the configured read-only MCP
media root, deletes the resulting LVS asset through MCP, removes the source
fixture, and proves exact REST catalog, media-root, and container-identity
restoration. It never invokes inference or stream tools, never uses the
Warehouse sample, and retains hashes instead of file IDs, names, paths, session
IDs, responses, or credentials.

Run the bounded transaction with:

```bash
python3 executor.py \
  --ack I_AUTHORIZE_LVS_MCP_DISPOSABLE_FILE_LIFECYCLE_AND_EXACT_CLEANUP
```

Validate the retained receipt offline with:

```bash
python3 verify.py
pytest -q tests
```

The sealed 2026-08-11 run is summarized in `official-runtime-evidence.json`.
Its canonical capability projection is generated by
`build_capability_evidence.py`; neither evidence layer expands the receipt's
explicit non-inference boundary.
