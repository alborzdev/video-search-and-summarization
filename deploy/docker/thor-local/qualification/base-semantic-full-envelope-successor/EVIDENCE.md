# Evidence boundary

## Source-locked facts

The inert compiler byte-locks both predecessors, the selected schema-v2
500-row oracle artifact, the Agent OpenAPI inventory, exact-file filesystem
object-store deletion, all three timestamped report writers, and the report
agent's Markdown/PDF link formatter. It then mechanically proves that:

- the semantic step lists are the frozen predecessor workflows after removing
  the invalid namespace probe/cleanup and replacing HITL's guessed render paths;
- Agent advertises the two semantic POST families, the HITL interaction POST,
  and exact-key static GET/DELETE routes;
- the selected Base rows remain `open_unexecuted`, planning-only, null-bound,
  empty-evidence rows with their historical 8/11 bounds;
- the exact-cleanup predecessor derives 11/12 as the successful full envelopes;
- each successor envelope contains its five/six semantic requests plus exactly
  two reads, two deletes, and two per-key absence checks.
- each case admits report links from exactly one source-locked report step;
  other semantic responses cannot register cleanup ownership even if they
  contain syntactically valid report URLs.

The schemas prohibit raw paths in artifact evidence, recursive/namespace
cleanup claims, canonical advancement, and promotion. Mock transports cover
both successful envelopes, cleanup after a later semantic failure, cleanup
after a read failure, cleanup failure reporting, numeric-loopback admission,
manifest drift, ambiguous report output, cross-step report-link injection,
receipt order, and forgery rejection.

## Not proven

No live command is run by the plan or tests and no checked-in runtime receipt
exists. This package does not deploy services, access Docker or credentials,
stage models, download media, call a network endpoint, prove Thor capacity, or
qualify actual model output. It does not prove pre-creation absence for a
timestamp-derived upsert, change the selected Metadata-500 rows, establish a
canonical executor binding, or promote either capability. Warehouse and its
sample bundle remain excluded.
