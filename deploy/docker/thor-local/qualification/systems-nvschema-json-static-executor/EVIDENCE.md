# Evidence boundary

The contract locks the exact canonical planning row, capability, oracle, Wave 7 predecessor, systems candidate, and 8 checked-in product/test files used by the executor. Every locked file is independently re-hashed before product code is imported.

Positive static observations:

- The real Behavior Analytics legacy converter maps the documented frame fields and delimited 2D object into generated NvSchema Protobuf, including bounding box, confidence, pose, and embedding; deterministic serialization survives a byte-identical parse/serialize round trip.
- The real Spatial AI loader preserves a custom field in raw mode and projects 3D location, scale, rotation, timestamp, and info in flattened/row modes.
- The real agent Pydantic model emits the released incident aliases, including `Id`, `sensorId`, `objectIds`, and `analyticsModule`.

Adjacent checks show four malformed inputs reject, while two boundaries are explicitly recorded as limitations: the Spatial AI row iterator does not project legacy `@timestamp`, and the Behavior frame converter does not enforce the illustrative documentation's event-value enumeration.

This is static product-code evidence, not an end-to-end broker or deployed-service protocol round trip. It cannot mark the capability `passed_current`, materialize the planning executor, close the oracle, or supply runtime evidence. The Warehouse sample bundle is explicitly excluded.

Each observation loads a fresh product-module subset and restores the caller's exact `sys.path` and relevant `sys.modules` entries. Zero external-call accounting is an assertion from the locked source/import-boundary audit, not general-purpose instrumentation of every transitive dependency.
