# Evidence boundary

## What a pass proves

The receipt proves that the canonical capability/oracle bindings are present,
their non-qualified states have not been promoted, all nine product, candidate,
and planning sources match exact byte locks, and the checked-in official-edge
configuration
uses:

- artifact `ngc:nim/nvidia/cosmos3-nano-reasoner:bf16-final`;
- served ID `nim_nvidia_cosmos3-nano-reasoner_bf16-final`; and
- selector `cosmos-reason3` for the default RT-VLM and agent-VLM roles.

It also proves that Smart City retains the official `3.2.1` docs-container,
`VSS v3.1` TOC, `3.2.0 microservices` release-note, and `VSS 3.0
architecture` deep-dive statements as a mismatch. The grouped release-note
bullet is not treated as component-level version evidence.

## What a pass does not prove

This package produces no runtime evidence. It does not prove that the Cosmos
artifact is staged, that `/v1/models` serves the locked ID, that semantic video
inference works, or that every Smart City component has a resolved immutable
image/artifact digest. Those checks remain open and require a separately
authorized bounded runtime execution using operator custom media. The large
Warehouse sample bundle is not required.

The executor intentionally does not call the product verifier's Git-backed
source-anchor function. It invokes only its five file/config verification
functions, while independently hashing every selected implementation source.
