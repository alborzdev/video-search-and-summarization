# Evidence boundary

This package proves a current-source, static-only rebase of the 71 retained
advertised-entry candidate rows. It locks the immutable predecessor inventory
and receipt, resolves all 182 row/source references using exactly seventeen changed
paths, and preserves the exact 34 unchanged / 37 rebased partition.

The `video_report_gen.py` overlay is referenced by three retained rows. It moves
only `manifest-gap.audio-understanding.00-audio-aware-base-workflow` from the
unchanged partition; its other two references were already rebased by existing
overlay paths.

The current Thor VIOS media source is provenance-bound for all five retained
codec/audio rows, moving those rows into the rebased partition.

The changed semantics are checked directly against current source: guarded
Kafka publication suppresses work after abort/finalization, and the Agent/NAT
inventory is exactly 64 operations (the historical 44 plus 12 Search routes and
eight released agent routes) while retaining all eight required generate/chat
routes.

This is not runtime evidence. Historical dispatch is not replayed, the old
receipt is not relabelled, no capability is promoted, and the Warehouse sample
remains excluded. No network, Docker, service lifecycle, credential, download,
browser, or host mutation is available through the validator.
