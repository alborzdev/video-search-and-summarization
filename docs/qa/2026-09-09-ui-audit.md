## Implemented changes

- Brand CSS uses semantic backgrounds directly, avoiding specificity battles with
  the previous dark-mode override list. White media text remains white.
- Dark logo uses the unmodified original color asset; light mode keeps its black
  wordmark. The decorative flattening filter is removed.
- Home hero stacks at intermediate widths; search has a full-width query and a
  wrapping filter row. Results switch to one column on narrower desktop widths.
- Metadata and supporting labels increased to 11–12 px where previously 7–10 px.
  Camera grid switches to two columns at intermediate widths. Narrow mobile
  navigation retains seven labeled destinations without collisions.
- Primary navigation resets the document scroll position. Mobile navigation is
  fixed to the viewport. Modal scrolling no longer scrolls the page underneath.
- Primary actions retain their accent fill; keyboard input/select focus is visible.
- Blank video previews explain that no preview is available and offer play.
- Old index timestamps include days/date; home no longer declares normal operation
  from the absence of verified incidents. Unknown source state says Checking.
- Focused-camera status panel scrolls within the space above the analyst composer.
  The fallback-frame notice is placed where it is not hidden by that composer.
- Removed the unqualified eight-source capacity promise from Capabilities.
- Video history introduction uses user-facing language rather than database names.

## Testing limits

This is a UI/readiness audit, not a semantic-accuracy certification or load test.
The cited model answer still requires human review (the returned description of
stationary vehicles should be compared against the moving clip). Older RTSP
sources can fall back to retained frames; this audit did not reconnect unavailable
external feeds, start new camera workloads, or validate all historical retention
windows. New uploads, destructive source actions, rule activation and saving new
incidents were not exercised. Upload entry was inspected; OS file selection was
not submitted. Multi-camera/long-running inference qualification remains separate.
