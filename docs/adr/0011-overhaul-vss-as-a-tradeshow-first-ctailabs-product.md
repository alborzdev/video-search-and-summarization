# Overhaul VSS as a tradeshow-first CTAILabs product

This codebase will become a visually compelling, tradeshow-reliable CTAILabs product built around live video, visible analytics, and natural-language interaction. It will portray a credible Operations Analyst workflow, but it is not the exact application CTAILabs expects to ship to production soon; enterprise completeness and migration compatibility must not slow the overhaul. NVIDIA services remain useful foundations, while future upstream improvements will be inspected and selectively ported through agentic development rather than preserved through merges or a path back to NVIDIA's UI.
