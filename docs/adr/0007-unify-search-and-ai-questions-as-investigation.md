# Unify search and AI questions as Investigation

Semantic search, live visual questions, historical summaries, and follow-up questions will appear through one Investigate experience rather than asking users to choose a backend. Each query may return an Evidence-backed answer, matching Events and clips, camera and time context, and suggested follow-ups. The interface will expose an explicit Live Context for questions about current activity so it never implies analysis of unseen frames.
