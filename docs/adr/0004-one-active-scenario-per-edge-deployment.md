# One Active Scenario per Edge Deployment

An Edge Deployment will run one Active Scenario across one or more cameras. CTAILabs may install several Scenario Templates on a tradeshow Thor and switch between them deliberately, but unrelated warehouse and traffic sources, rules, terminology, and analytics will not coexist in one Operations workspace. This keeps every live view and investigation internally coherent while retaining a common application shell across industries.
