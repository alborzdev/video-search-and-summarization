# Configurable Showcase with curated Scenario Templates

The Showcase will remain one scenario-agnostic, production-shaped application rather than a collection of bespoke demo interfaces. CTAILabs will package curated Scenario Templates that select the RTSP sources, models, analytics, rules, and defaults for each industry; an Edge Deployment is one NVIDIA Thor processing one or more camera streams. This preserves a consistent operator experience while allowing CTAILabs to tune each environment without exposing infrastructure assembly to the customer.
