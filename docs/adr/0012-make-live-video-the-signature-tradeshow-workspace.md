# Make live video the signature tradeshow workspace

The signature Showcase screen will center a large selected Live Source with toggleable Analytics Layers, compact live metrics, the Activity Feed, and immediate access to the Vision Analyst without obscuring the video. The default layer set remains restrained, while Presenters may independently expose boxes, tracks, zones, counts, captions, and rule indicators. Contextual Suggested Questions invoke the real system, and a pre-show health gate plus clearly labeled local Fallback Sources preserve the workflow when live dependencies fail.
