Rule cards distinguish the number in an area from the number of active stop/dwell/direction alerts. This can mean a track gap or missing speed evidence even when both cameras are live; it does not show a retained count as current. Predictions, blind intervals and a track's display-cache expiry do not prove that an object departed. Duration rules must qualify again after a long gap. Evicted inside tracks retain bounded unresolved identity evidence; an unrelated outside object cannot clear the old incident. Explicitly selected historical events remain available for review even while live analysis is unavailable.
